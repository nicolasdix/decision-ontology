# Data Collection

This part contains everything related to the dataset collection.

## Structure
- `raw/` – here you can find all raw datasets that I am able to distribute. For those where I am not able to reupload them, you can find the source in the dataset inventory file
- `summary_table.csv` – This spreadsheet summarizes the main attributes from each dataset
- `dataset_inventory.csv` – This spreadsheet contains metadata for each dataset
